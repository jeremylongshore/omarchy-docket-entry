# Test Personas

## GitHub reviewer

Needs the oldest human review obligations first, an overdue signal, and a drain action that does not permanently mute changed work.

## Pull request author

Needs own work split into blocked and ready-to-merge lanes without drafts or waiting-on-others noise.

## Privacy-conscious Omarchy user

Needs a local credential workflow that keeps tokens out of argv, publishes a private file safely, and fails closed under path replacement.

## Marketplace maintainer

Needs exact-SHA deterministic CI, a complete description, a distinctive authored banner, and a real populated Buzz screenshot whose source and shell log are bound to the receipt.
