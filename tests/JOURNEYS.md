# Acceptance Journeys

## Connect to actionable docket

1. Pipe a GitHub token to `docket-login` without exposing it in argv.
2. Publish private credentials through the descriptor-bound helper.
3. Poll one bounded GraphQL document for review requests and authored PRs.
4. Classify results into Review, Blocked, and Ready lanes oldest first.
5. Open the panel and read overdue state by pointer or keyboard.
6. Open or drain the selected PR; a later PR update restores a drained item.

2. Commit the clean source tree.
3. Run Buzz validation and qmllint against that exact source package.
4. Feed a scrubbed response through the real Service curl/parse/classify flow.
5. Toggle the real panel, exercise its drain action, and capture the direct 1280x720 frame.
6. Verify receipt hashes, run ID, raw shell-log SHA, image salience, and expected three-lane story.
